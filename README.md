# Kevinomat (Ich glaube diese funktioniert)

Ein kleines Glücksrad für Kevin: Es entscheidet zufällig zwischen **der**, **die** und **das**.

## Start

`index.html` doppelklicken oder den Ordner mit einem lokalen Webserver öffnen.

## Enthalten

- animiertes Artikel-Glücksrad
- echte Sounds direkt aus der WebAudio-API, ohne Audiodateien
- Konfetti, Emoji-Popups, Toasts und Chaos-Button
- Verlauf der letzten Entscheidungen
- responsive Darstellung und Unterstützung für reduzierte Bewegung
